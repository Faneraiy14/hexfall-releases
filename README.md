# HEXFALL — releases / релізи

## Українською

Тут лежать збірки гри **HEXFALL** — мобільної арени магів 3 на 3.

**Гра ще в розробці.** Релізи в цьому репозиторії — для закритого тесту.
Якщо ви завантажите APK і встановите його, гра **не запуститься**: вона покаже екран «ЗАКРИТИЙ ТЕСТ»,
бо на вашому пристрої немає ключа тестувальника. Це не помилка — так задумано, поки гра не готова.

Коли гра буде готова, тут з'являться відкриті версії, і про це буде написано в цьому файлі.

## In English

This repository holds builds of **HEXFALL**, a 3v3 mobile sorcerer arena.

**The game is still in development.** Releases here are for a closed test.
If you download an APK and install it, the game **will not start**: it shows a "CLOSED TEST" screen,
because your device has no tester key. This is not a bug — it is intentional until the game is ready.

Once the game is ready, open versions will appear here, and this file will say so.
