# HEXFALL — releases / релізи

## Українською

**HEXFALL** — мобільна арена магів 3 на 3 для Android. Сім магів, у кожного своя атака, супер і **Печать** —
зона з власними правилами. Режими: Битва, Зорепад, Оплот, Зіткнення (соло/дуо/тріо), «Навала» з друзями проти боса
і сезонний режим. Сезони кожні 6 тижнів — з подарунком на старті й новинками.

### Як встановити
1. Відкрийте [останній реліз](https://github.com/Faneraiy14/hexfall-releases/releases/latest) і завантажте файл `hexfall-<версія>.apk`.
2. Відкрийте завантажений файл. Якщо телефон попросить — дозвольте встановлення з цього джерела (браузера чи файлового менеджера).
3. Готово. Нові версії гра далі ставить сама: на екрані завантаження вона перевіряє оновлення.

Потрібен Android 5.0 або новіший. Гра з другом працює, коли ви в одній Wi-Fi мережі;
гра через інтернет з'явиться пізніше.

Якщо у вас стояла версія закритого тесту (до 1.1.0), спершу видаліть її — нові версії підписані іншим ключем.

## In English

**HEXFALL** is a 3v3 mobile sorcerer arena for Android. Seven mages, each with an attack, a super and a **Seal** —
a zone with its own rules. Modes: Battle, Shard Fall, Stronghold, Showdown (solo/duo/trio), co-op Horde against a boss,
and a seasonal mode. Seasons last 6 weeks, each starting with a gift and something new.

### How to install
1. Open the [latest release](https://github.com/Faneraiy14/hexfall-releases/releases/latest) and download `hexfall-<version>.apk`.
2. Open the downloaded file. If your phone asks, allow installing from this source (your browser or file manager).
3. Done. The game installs new versions by itself: it checks for updates on the loading screen.

Requires Android 5.0 or newer. Playing with a friend works on the same Wi-Fi network;
online play over the internet will come later.

If you had a closed-test build installed (before 1.1.0), uninstall it first — new versions are signed with a different key.
